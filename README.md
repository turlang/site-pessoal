# Site Pessoal — Evandro Ricardo

Site pessoal desenvolvido para apresentar trajetória profissional, projetos, habilidades e objetivos como desenvolvedor web.

## Preview

![Preview do Site Pessoal](docs/preview.svg)

## Principais seções

- Apresentação profissional.
- Sobre mim.
- Projetos em destaque.
- Habilidades técnicas.
- Links para GitHub e LinkedIn.

## Stack

- HTML5
- CSS3
- JavaScript

## Como executar

Abra o arquivo `index.html` no navegador ou utilize um servidor local:

```bash
npx serve .
```
